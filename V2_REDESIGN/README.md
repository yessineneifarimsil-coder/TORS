# V2_REDESIGN — routing-policy selection, redesigned study

**This directory is Version 2. It does not touch Version 1.**

Version 1 is the completed TORS submission in `../routing_regime_study/`. Nothing in that
directory is modified, reinterpreted, or re-run by anything here. V1 results stand as published;
V2 results, when they exist, will come from new experiments only.

## Status

Design phase. **No V2 experiment has been run and no V2 result exists.** Every quantity in these
documents is a specification, a hypothesis, or a figure carried over from V1 and labelled as such.

## Gate

The full ML study is **not authorised** until the complementarity screen in
`experiments/SCREENING_EXPERIMENT.md` returns a portfolio with experimentally demonstrated
complementary strengths. A negative screen is a publishable result and will be reported as one.
