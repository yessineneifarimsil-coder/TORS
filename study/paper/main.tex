\section*{Reproducibility}
All scenario, policy, simulation and analysis code, every run record, and the
scripts that generate every number, table and figure in this paper are in the
accompanying repository. The experiment specification was committed before any
evaluation run was executed, and one protocol deviation is recorded with its
reasons.
